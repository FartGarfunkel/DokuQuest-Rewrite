DokuQuest sounds
================
Every sound the game makes has a placeholder here (<name>.txt), sorted into blocks/, mobs/ and effects/.
The game makes all of them itself (synthesised), so nothing here is needed.

To use your own recording for a sound, put <name>.wav (or .mp3 / .flac) next to its .txt (any folder under
sounds/ works; only the file name matters), e.g. blocks/stone/stone.step.wav or mobs/zombie/zombie_hurt.wav.
Recordings in <your DokuQuest folder>/sounds/ win over the ones here, so you can test without touching the game files.
Music and ambience are still generated and can't be replaced yet.
